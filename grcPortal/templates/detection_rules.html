Configure detection rules with alert prioritization and response procedures

Page Introduction

The Detection Rules page enables security teams to configure automated threat detection mechanisms. It provides a comprehensive framework for creating, managing, and monitoring detection rules that identify suspicious activities, security incidents, and potential threats in real-time across the organization's infrastructure.

How this page works:
  • Overview Cards: Shows metrics for critical rules, high priority rules, enabled rules, and total rules configured
  • Detection Rules Table: Lists all configured rules with details including name, type, description, severity, status, actions, and last triggered time
  • Alert Prioritization Framework: Defines response procedures based on priority levels (Critical, High, Medium, Low) with specific timeframes and escalation paths
  • Recent Incidents Section: Displays recent security incidents for detection validation and rule effectiveness assessment
  • Rule Configuration Modal: Interactive form for creating/editing rules with conditions, operators, values, time windows, and automated actions
  • Interactive Features: View rule details, edit existing rules, delete rules, and add new conditions dynamically

Alert Prioritization Framework
Priority Levels
Critical (Immediate Response):
• Known active threats with high confidence
• Indicators matching current campaigns
• Compromised critical systems
High (Rapid Response):
• Medium confidence matches
• Emerging threat patterns
• Anomalous behavior detection
Response Procedures
  • Critical: Immediate isolation, executive notification, incident response team activation
  • High: Within 1 hour investigation, security team notification
  • Medium: Within 4 hours review, monitoring enhancement
  • Low: Daily review, trend analysis
