Risk Monitoring

Continuous monitoring of risk indicators and key risk metrics

About This Page

The Risk Monitoring page provides continuous oversight of risk indicators and key performance metrics. It enables proactive risk management by tracking trends and alerting when thresholds are breached.

How This Page Works:
  • Indicator Cards: Visual summary of each risk indicator showing current values, targets, and status
  • Leading vs Lagging: Monitors both predictive indicators (leading) and outcome measures (lagging)
  • Status Thresholds: Color-coded alerts (Normal/Warning/Critical) based on configured thresholds
  • Detailed Table: Comprehensive view of all indicators with data sources, thresholds, and last readings
  • Refresh Data: Manual refresh capability to update indicator values from data sources
  • Monitoring Guidelines: Built-in help explaining indicator types and alert thresholds

Use the refresh button to get the latest data and monitor for any indicators requiring attention.
