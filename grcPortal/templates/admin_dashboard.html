Page Introduction

The Admin Dashboard provides a comprehensive overview of the GRC Portal's system status, user management, and key metrics. This centralized hub allows administrators to monitor system health, manage users, and access critical administrative functions.

Functionality Overview:
  • System Metrics: View real-time statistics including total users, active incidents, total risks, and incident counts to understand system status at a glance.
  • User Role Distribution: Monitor the breakdown of user roles (Administrators, Auditors, Users) to ensure proper access control and organizational structure.
  • Quick Actions Panel: Access frequently used administrative functions such as user management, audit log viewing, digital forensics, and system monitoring.
  • Recent Activity Feed: Stay informed about recent system activities and status updates to identify potential issues or maintenance needs.
  • Administrative Controls: Centralized access to all administrative features and settings for efficient system management.
  • Compliance Monitoring: Overview of key compliance-related metrics and quick access to audit and monitoring tools.
