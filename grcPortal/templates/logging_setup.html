System Logging Configuration

Comprehensive logging setup for security monitoring, audit trails, and incident response across multiple platforms.

Linux System Logging (rsyslog)

Installation:
sudo apt update
sudo apt install rsyslog
Configuration:
sudo nano /etc/rsyslog.conf
Security Logging Configuration:
# Security events
auth,authpriv.*                 /var/log/auth.log
*.*;auth,authpriv.none          -/var/log/syslog
kern.*                          -/var/log/kern.log

# Remote logging
*.* @@logserver.example.com:514
Log Rotation:
sudo nano /etc/logrotate.d/rsyslog

Windows Event Logging

Enable Advanced Audit Policies:
gpedit.msc
Computer Configuration → Windows Settings → Security Settings → Advanced Audit Policy Configuration
PowerShell Logging:
# Enable PowerShell transcription $regPath = "HKLM:\SOFTWARE\Policies\Microsoft\Windows\PowerShell\Transcription" New-ItemProperty -Path $regPath -Name "EnableTranscripting" -Value 1 -PropertyType DWORD # Enable PowerShell module logging $regPath = "HKLM:\SOFTWARE\Policies\Microsoft\Windows\PowerShell\ModuleLogging" New-ItemProperty -Path $regPath -Name "EnableModuleLogging" -Value 1 -PropertyType DWORD
Event Log Sizes:
wevtutil sl Security /ms:104857600 # 100MB
wevtutil sl System /ms:104857600
wevtutil sl Application /ms:104857600

macOS Unified Logging

View System Logs:
log show --last 1h
log stream --level debug
Security Event Logging:
# Enable security logging sudo log config --mode "level:debug,persist:debug" --subsystem com.apple.security
Export Logs:
log collect --output ~/Desktop/logs.logarchive

Log Aggregation & SIEM Integration

ELK Stack Setup:
# Install Elasticsearch
wget -qO - https://artifacts.elastic.co/GPG-KEY-elasticsearch | sudo apt-key add -
sudo apt install elasticsearch

# Install Logstash
sudo apt install logstash

# Install Kibana
sudo apt install kibana
Wazuh Integration:
# Configure Wazuh agent for log collection
sudo /var/ossec/bin/agent-auth -m 192.168.1.100
sudo systemctl restart wazuh-agent

Log Analysis & Monitoring

Common Log Analysis Commands:
# Failed login attempts
grep "Failed password" /var/log/auth.log

# System errors
grep "ERROR" /var/log/syslog

# Network connections
netstat -tuln | grep LISTEN
Automated Monitoring:
  • Logwatch for daily reports
  • Fail2ban for intrusion prevention
  • OSSEC/Wazuh for real-time monitoring
  • Custom scripts for anomaly detection

Compliance & Log Retention

Retention Policies:
  • Security logs: 1-7 years (depending on compliance requirements)
  • System logs: 90-365 days
  • Audit logs: 3-7 years
  • Application logs: 30-90 days
Compliance Standards:
  • PCI DSS: 1 year minimum for audit logs
  • SOX: 7 years for financial transaction logs
  • HIPAA: 6 years for health information logs
  • GDPR: Variable based on data sensitivity
Secure Log Storage:
Important: Implement write-once-read-many (WORM) storage and regular integrity checks for compliance logs.
