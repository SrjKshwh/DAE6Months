About Collected Logs

This page displays security logs collected from various sources for monitoring and analysis. Review log entries, analyze patterns, and create risk assessments from log data.

How it works:
  • Log Statistics: View summary statistics by severity and log type
  • Log Entries: Browse paginated log entries with filtering options
  • View Details: Examine full log messages and metadata
  • Create Risks: Generate risk assessments from suspicious log entries
  • Security Analysis: Link to security event analysis tools
