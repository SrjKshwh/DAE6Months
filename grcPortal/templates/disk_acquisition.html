Disk Acquisition

Page Introduction

The Disk Acquisition module provides tools for creating forensic disk images and managing disk evidence in incident response scenarios. It ensures proper acquisition procedures, integrity verification, and secure storage of disk images for legal admissibility.

How this page works:
  • Acquisition Overview: Displays current acquisition status, completed images, and system information
  • Start Acquisition Modal: Interactive form for initiating disk acquisition with target selection and parameters
  • Upload Disk Image Modal: Allows uploading existing disk images with integrity verification
  • Acquisition History: Shows previous acquisitions with timestamps, hash values, and status
  • Integrity Verification: Automatic hashing and verification of all acquired disk images
  • Chain of Custody: Maintains proper documentation and tracking of disk evidence
