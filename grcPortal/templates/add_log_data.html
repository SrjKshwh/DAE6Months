Page Introduction

This page allows you to add log data to the GRC Portal for security event analysis and monitoring. You can input individual log entries or upload bulk log data from various sources to build a comprehensive log database for threat detection and compliance reporting.

Functionality Overview:
  • Individual Log Entry: Manually add single log entries with detailed information including source name, log type, severity, category, and message content.
  • Bulk Log Upload: Upload multiple log entries at once by pasting formatted log data (timestamp, severity, message format).
  • Sample Templates: Use pre-built sample data templates for authentication, system, and security logs to understand the expected format and quickly populate test data.
  • Log Categories: Support for various log types including security, system, application, authentication, access, audit, firewall, and error logs.
