Page Introduction

The Environmental Changes page monitors and tracks external factors that could impact the organization's risk posture. It provides visibility into changes in the business environment, regulatory landscape, technology ecosystem, and other external variables that may affect security, compliance, and operational risks.

How this page works:
  • Summary Cards: Displays total changes detected, critical changes requiring immediate attention, unassessed changes, and mitigated changes
  • Changes Timeline: Presents environmental changes in chronological order with visual markers indicating severity levels (Critical=Red, High=Orange, Medium=Blue)
  • Change Details: Each timeline entry shows change type, description, severity, detection date, impact assessment, risk implications, and current status
  • Status Tracking: Changes progress through states: Detected (unassessed), Assessed, Mitigated, with clear visual indicators for each status
  • Navigation Links: Quick access to related pages like Risk Indicators and Risk Dashboard for comprehensive risk management
  • Interactive Timeline: Custom CSS styling creates a visual timeline with markers and content cards for easy scanning of environmental changes
