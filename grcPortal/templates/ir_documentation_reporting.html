Incident Response Playbook
Response Procedures for Common Incidents

1. Detection & Identification
  • Monitor for unusual system behavior (high CPU, network activity)
  • Check Wazuh alerts for malware signatures
  • Run Volatility memory analysis: vol.py -f memory.dmp windows.malfind
  • Isolate affected system immediately
2. Containment
  • Disconnect network interfaces: ifconfig eth0 down
  • Implement firewall rules: iptables -P INPUT DROP
  • Stop suspicious processes: kill -9
  • Disable affected user accounts
3. Eradication
  • Remove malware files and registry entries
  • Clean temporary files: rm -rf /tmp/*
  • Update antivirus signatures
  • Patch known vulnerabilities
4. Recovery & Lessons Learned
  • Restore from clean backups
  • Monitor for 72 hours post-recovery
  • Document incident details and response actions
  • Update playbooks based on lessons learned

Incident Report: IR-2024-001
Report Sections

Incident Overview

On January 15, 2024, at approximately 09:15 UTC, the security monitoring system detected suspicious file encryption activity on three critical systems running Parrot OS. The incident was classified as a ransomware infection with data exfiltration capabilities.

Impact Assessment
  • Business Impact: High - Operations disrupted for 6.75 hours
  • Data Exposure: Minimal - Contained before significant exfiltration
  • Financial Impact: $45,000 in recovery costs and lost productivity
  • Reputation Impact: Low - Internal incident, no external disclosure required
Root Cause

The incident originated from a phishing email that delivered a malicious macro-enabled document. The user executed the macro, which downloaded and installed ransomware payload. The malware used advanced evasion techniques to avoid detection initially.

Malware Analysis
  • Malware Family: Ryuk Ransomware
  • Delivery Method: Phishing email with malicious attachment
  • Execution: PowerShell script with obfuscation
  • Encryption: AES-256 + RSA-4096 hybrid
  • C2 Communication: HTTPS to compromised domains

IR Tools Documentation in Parrot OS
Tool Categories & Usage

Wazuh SIEM
  • Purpose: Real-time security monitoring and alerting
  • Installation: curl -s https://packages.wazuh.com/key/GPG-KEY-WAZUH | apt-key add - && apt install wazuh-agent
  • Configuration: /var/ossec/etc/ossec.conf
  • Usage: wazuh-control start to start agent
  • Logs: /var/ossec/logs/
Wireshark/tshark
  • Purpose: Network traffic analysis and capture
  • Installation: apt install wireshark tshark
  • Capture: tshark -i eth0 -w capture.pcap
  • Analysis: tshark -r capture.pcap -Y "http"
  • Filters: Display filters for protocol-specific analysis

Volatility Framework
  • Purpose: Memory analysis and malware detection
  • Installation: apt install volatility
  • Profile Detection: vol.py -f memory.dmp imageinfo
  • Process Analysis: vol.py -f memory.dmp --profile=Linux pslist
  • Malware Hunting: vol.py -f memory.dmp malfind
dc3dd (Disk Imaging)
  • Purpose: Forensic disk imaging with hashing
  • Installation: apt install dc3dd
  • Basic Imaging: dc3dd if=/dev/sda of=image.img
  • With Hashing: dc3dd if=/dev/sda of=image.img hash=sha256 log=dc3dd.log
  • Verification: Automatic hash verification during acquisition

Common Issues & Solutions
  • Wazuh connection issues: Check firewall and manager IP
  • Volatility profile errors: Ensure correct profile selection
  • Disk imaging failures: Verify disk permissions and space
  • Memory dump issues: Check kernel module compatibility
