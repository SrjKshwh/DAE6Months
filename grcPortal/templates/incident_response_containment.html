Containment Playbook - VirtualBox Environment
Host Isolation Steps
Step 1: Immediate Network Isolation

Action: Disconnect all network interfaces

sudo ifconfig eth0 down && sudo ifconfig wlan0 down
Prevents lateral movement and data exfiltration
Step 2: VirtualBox Network Configuration

Action: Switch to host-only network mode

VBoxManage modifyvm "Parrot-IR" --nic1 hostonly --hostonlyadapter1 vboxnet0
Isolates VM from external networks while maintaining host access
Step 3: Firewall Containment Rules

Action: Implement strict firewall policies

sudo ufw --force enable && sudo ufw default deny incoming && sudo ufw default deny outgoing
Blocks all network communication except essential services
Step 4: Process Isolation

Action: Identify and isolate suspicious processes

sudo ps aux | grep suspicious && sudo kill -STOP
Stops malicious processes without terminating them
Step 5: Evidence Collection

Action: Preserve volatile evidence

sudo volatility -f /dev/mem --profile=LinuxUbuntu16045x64 pslist > process_list.txt
Captures running processes and memory state
