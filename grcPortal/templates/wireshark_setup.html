Wireshark Network Protocol Analyzer Setup

Wireshark is a powerful network protocol analyzer used for network troubleshooting, analysis, and security auditing.

Installation

Ubuntu/Debian Installation:
sudo apt update
sudo apt install wireshark
Parrot OS Installation:
sudo apt update
sudo apt install wireshark
Windows Installation:
Download from: https://www.wireshark.org/download.html
Run installer as Administrator

Configuration

Grant Permissions (Linux):
sudo usermod -a -G wireshark $USER
sudo chmod +x /usr/bin/dumpcap
Basic Configuration:
  • Enable promiscuous mode for network interfaces
  • Configure capture filters for specific traffic
  • Set up display filters for analysis
  • Enable protocol dissection preferences

Usage Examples

Capture Network Traffic:
wireshark
# or
wireshark -i eth0 -k
Command Line Capture:
tshark -i eth0 -w capture.pcap
Filter Examples:
  • http - HTTP traffic only
  • tcp.port == 443 - HTTPS traffic
  • ip.src == 192.168.1.1 - Traffic from specific IP
  • dns - DNS queries and responses

Security Features

  • Protocol Analysis: Deep inspection of network protocols for anomalies
  • Traffic Pattern Recognition: Identify suspicious network behavior
  • Encryption Detection: Monitor SSL/TLS handshake and certificate validation
  • Malware Traffic Analysis: Detect command and control communications

Evidence Collection

Capture File Formats:
  • PCAP - Standard packet capture format
  • PCAPNG - Next generation PCAP format
  • Hash verification for chain of custody
Documentation Requirements:
Important: Document capture parameters, timestamps, and system information for legal admissibility.

Integration

Wireshark integrates with the IR environment through:

  • Network traffic correlation with Wazuh alerts
  • Packet capture during incident response
  • Protocol analysis for threat hunting
  • Evidence preservation for forensic analysis
