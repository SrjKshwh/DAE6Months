Authentication Failure Alerts
Alert Template: Failed Login Attempts
Alert ID: AUTH-001
Category: Authentication
Severity: High
Trigger Condition: 3+ failed password attempts within 10 minutes
Detection Method: Pattern matching on authentication logs
False Positive Rate: < 5%
Response Protocol
Immediate Actions:
  • Log security event with full context
  • Monitor for brute force patterns
  • Check account lockout status
Escalation Criteria:
  • 10+ attempts in 10 minutes → Security Team
  • Privileged account → Management
  • Multiple accounts affected → Incident Response
Evidence Collection:
  • Source IP addresses
  • Target account details
  • Timestamp correlation
  • Geographic analysis

Sensitive File Access Alerts
Alert Template: Unauthorized File Access
Alert ID: FILE-001
Category: File Access
Severity: High
Trigger Condition: Access to sensitive system files
Detection Method: File path pattern matching
False Positive Rate: < 2%
Response Protocol
Immediate Actions:
  • Verify access legitimacy
  • Check user permissions
  • Review access logs
Escalation Criteria:
  • System files (SAM, shadow) → Critical
  • Multiple unauthorized accesses → High
  • Privileged user involved → Management
Evidence Collection:
  • File access timestamps
  • User identity verification
  • Access pattern analysis
  • Business justification review

Severity: Medium

Detection Method: Firewall log analysis
False Positive Rate: < 10%
Response Protocol
Immediate Actions:
  • Verify block legitimacy
  • Check destination reputation

Escalation Criteria:
