# SQL 1 - Database Fundamentals

This directory contains materials for SQL 1 course focusing on database fundamentals.

## Contents

- [SQL_1.pdf](SQL_1.pdf) - Main course material covering:
  - Introduction to relational databases
  - Basic SQL queries (SELECT, INSERT, UPDATE, DELETE)
  - Database design principles
  - Normalization concepts
  - Basic joins and relationships

## Course Objectives

By completing this module, you should be able to:
- Understand the basics of relational database management systems
- Write fundamental SQL queries
- Design simple database schemas
- Apply normalization techniques
- Create basic relationships between tables

## Prerequisites

- Basic understanding of computer systems
- Familiarity with data concepts

## How to Use

1. Read through the PDF material
2. Practice writing SQL queries
3. Experiment with creating your own database schemas
