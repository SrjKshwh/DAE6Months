## Word Search Game Demonstration
[Watch the demo video](https://youtu.be/hgybL4smxc8)
This video showcases the functionality of a desktop Word Search puzzle game.

### Key Features Demonstrated (quick introduction throught video):

1.  **Custom Word List Creation (0:00-0:12):**
    * The user types three custom words (`walmart`, `petsmart`, `khols`) into input boxes.
    * The user clicks **"Add to list"** to compile the final list of words to be found in the puzzle. The resulting list is displayed in the main window (e.g., PAPAYA, CARINET, DRUMS, APPLE, etc., plus the newly added words).

2.  **Gameplay Start and Timer (0:15-0:23):**
    * The user clicks **"Start"** to begin the game, which immediately initiates a visible timer (tracking time in seconds).

3.  **Word Finding (0:24-0:40):**
    * The user interacts directly with the letter grid to highlight a found word.
    * The word **"APPLE"** is successfully found by clicking and dragging diagonally.
    * Upon successful selection, the corresponding word on the list is visually marked as found (e.g., by highlighting or removing it).

4.  **Game Controls (0:40-0:50):**
    * The remaining time and score are continuously displayed.
    * The **"Pause"** button is used, which temporarily stops the timer and game activity.
    * The user shows the **"Show Score & Reset"** and **"Undo all clicks"** buttons, demonstrating game management controls (this project was made from scratch)
