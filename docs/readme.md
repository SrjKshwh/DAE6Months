# Documentation

This folder contains the documentation site built with Jekyll, including pages, assets, and configuration files.

## Contents

- `index.md`: The main landing page of the documentation site.
- `about.md`: Information about the project or author.
- `contact.md`: Contact details and information.
- `projects.md`: Showcase of projects.
- `resume.md`: Professional resume or CV.
- `404.md`: Custom 404 error page.
- `_config.yml`: Jekyll configuration file.
- `assets/`: Directory containing CSS, images, and other static assets.
- `_includes/`: Reusable HTML components.
- `_data/`: Data files for site configuration.
- `adr/`: Architecture Decision Records.

This is a Jekyll-based documentation site. To run locally, ensure Jekyll is installed and run `jekyll serve` from this directory.
