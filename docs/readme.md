# 📚 Documentation Site

Welcome to the documentation repository for my personal portfolio and project showcase! This Jekyll-powered site serves as a comprehensive hub for my professional journey, skills, and achievements.

---

## 📁 Project Structure

### Core Pages
- 🏠 **`index.md`**: Main landing page with introduction and key highlights
- 👤 **`about.md`**: Personal background and professional overview
- 📞 **`contact.md`**: Contact information and professional networks
- 🚀 **`projects.md`**: Detailed showcase of current and past projects
- 📄 **`resume.md`**: Complete professional resume with experience and skills
- 🚫 **`404.md`**: Custom error page for broken links

### Configuration & Assets
- ⚙️ **`_config.yml`**: Jekyll site configuration and theme settings
- 🎨 **`assets/`**: Static resources including CSS stylesheets and images
- 🔧 **`_includes/`**: Reusable HTML components and templates
- 📊 **`_data/`**: YAML data files for dynamic content
- 🏗️ **`adr/`**: Architecture Decision Records documenting technical choices

## 🚀 Getting Started

This is a **Jekyll-based static site** designed for seamless deployment on GitHub Pages.

### Prerequisites
- Ruby (version 2.5.0 or higher)
- Bundler gem
- Jekyll

### Local Development
1. **Clone the repository** (if applicable)
2. **Install dependencies**:
   ```bash
   bundle install
   ```
3. **Serve locally**:
   ```bash
   bundle exec jekyll serve
   ```
4. **View the site** at `http://localhost:4000`

### Deployment
The site is configured for automatic deployment via GitHub Pages. Simply push changes to the main branch, and GitHub will handle the build and hosting.
